# moduchang-plan-guide

## 무엇을 하는 스킬인가

- 4문항(문제 인식 · 실현 가능성 · 성장전략 · 향후 발전방안)을 **작성 의도**에 맞게 다시 짬
- ■ 소제목만 읽어도 이해되는 결론형 소제목 사슬
- 표만 이어지지 않게 문항별 도식 배치, 증빙은 본문 근거 옆에
- 계획은 의지형 어미, 숫자는 단순하고 서로 맞게
- 상담자료 PDF · 수정안 · 묶음 zip까지의 멘토링 진행
