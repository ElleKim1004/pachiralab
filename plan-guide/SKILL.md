# 모두의창업 사업계획서 멘토링 가이드 — 김윤경 책임멘토

멘티 사업계획서를 **심사위원이 ■ 소제목만 읽어도 사업이 이해되는 문서**로 바꾸는 스킬이다. 실제 멘토링(2026.11, 2기)에서 멘토가 직접 고쳐 달라고 한 내용만 모았다.

## 이 스킬의 세 가지 원칙

1. **소제목이 곧 결론이다.** `■ N. 키워드 — 결론 문장` 형식. 한 문항 안의 ■는 위에서 아래로 논리가 이어진다.
2. **계획은 의지로, 사실은 사실로 쓴다.** 목표·계획은 "~에 도전하고자 함", "~할 예정임". 이미 한 일은 "받았음", "끝냈음".
3. **표만 이어지지 않게, 근거는 바로 옆에.** 문항마다 도식을 넣고, 사진·증빙은 붙임이 아니라 해당 근거 옆 본문에 넣는다.

## 파일 구성 — 작성 의도와 세부 작성법을 나눠 둠

| 파일 | 내용 | 언제 읽나 |
|---|---|---|
| `references/1-intent.md` | **작성 의도별 작성법과 개요** — Q1~Q4가 각각 심사위원에게 무엇을 증명해야 하는지, ■ 소제목 사슬, 넣을 도식 | 구조를 잡거나 문항을 다시 짤 때 |
| `references/2-writing-style.md` | **세부 문서작성** — 어미·문장·숫자·출처·금지 표현·시각화·증빙 배치·서식 | 문장을 쓰고 다듬을 때 |
| `references/3-mentor-workflow.md` | 멘토링 진행 순서와 산출물(상담자료 PDF, 수정안, 묶음) | 회차를 준비할 때 |
| `references/4-checklist.md` | 제출 전 점검표 | 수정안을 넘기기 직전 |

## 작업 순서

1. **양식 규정부터 확인한다.** 쪽수 한도·글꼴 크기·줄간격·문항별 글자 수·붙임 한도·파일명. 기수·라운드마다 바뀌므로 공고 양식 원본으로 확인하고, 확인이 안 되면 메모 페이지에 [확인]으로 남긴다.
2. 대표 초안을 `1-intent.md`의 문항별 개요에 대 보고 빠진 칸, 숫자 불일치, 결론이 없는 소제목을 찾는다.
3. 진단 상담자료(PDF)와 대표에게 물을 질문을 만든다 → `3-mentor-workflow.md`.
4. 수정안을 양식 문항 그대로 다시 쓴다 → `1-intent.md` 구조 + `2-writing-style.md` 문장 규칙.
5. `4-checklist.md`로 점검하고, 모르는 숫자는 지어내지 않고 빨간 `[ ]`로 남긴다.

## 업데이트 규칙

- 멘토가 새로 고쳐 달라고 한 것은 **같은 패턴 전체에 적용**하고(한 곳만 고치지 않음), 반복될 만한 규칙이면 해당 references 파일에 추가한다.
- 작성 의도(구조)에 관한 것은 `1-intent.md`, 문장·서식에 관한 것은 `2-writing-style.md`에 넣는다.
- 예시는 업종 일반 표현으로 쓰고, 멘티 회사명·거래처·숫자는 넣지 않는다.
