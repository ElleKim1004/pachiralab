# 2. 세부 문서작성

## 2-1. 어미 — 계획은 의지로, 사실은 사실로

| 구분 | 쓴다 | 쓰지 않는다 |
|---|---|---|
| 목표·계획 | ~에 도전하고자 함 · ~하고자 함 · ~할 예정임 · ~할 계획임 · ~해 다음 단계로 나아갈 예정임 · 반드시 ~하고자 함 | ~잡았음 · ~하겠음 · 계획을 사실처럼 쓴 "채움 / 만듦 / 돌림 / 감" |
| 이미 한 일 | 받았음 · 끝냈음 · 확보했음 · ~했고 | 의지형으로 바꾸지 않음(힘이 빠짐) |

- 문서 전체는 음슴체(~임/~함/~됨). 대표가 합니다체 예시를 주어도 문서 어미에 맞춘다.
- 예: "1%로 잡았음" → "1%를 목표로 도전하고자 함" / "세계 브랜드에 공급하겠음" → "세계 브랜드에 공급해 다음 단계로 나아갈 예정임"
- 어미를 고치라는 요청은 그 한 줄이 아니라 **문서 안의 같은 패턴 전체**에 적용한다.

## 2-2. 소제목과 본문

- 소제목 `■ N. 키워드 — 결론`. 핵심 숫자를 소제목에 넣는다. ("3년 새 1.6배", "월 10톤", "8.9억 원")
- 소제목에 무슨 말인지 알 수 없는 표현 금지. 멘토가 "핵심 메시지가 뭔지 모르겠다"고 하면 결론 문장으로 다시 쓴다.
- 본문은 소제목을 되풀이하지 않고 **새 정보만** 더한다.
- 한 문장은 한 줄(약 38자) 안, 구체 수치 포함, 다음 문단으로 넘치지 않게.
- 4개 이상 항목은 ①②③ 하위 라벨에 핵심 수치.
- 화살 문장(→)은 그 덩어리의 결론 한 줄에만.

## 2-3. 숫자

- **하나로 단순하게.** "US$335.6B ≈ 약 470조 원 (Market Glass, 2025)" → 본문은 "470조 원", 출처는 아래 작은 글씨.
- 산식은 표 안에 보인다(단가 × 수량, (공급가 − 원가) ÷ 공급가).
- 문항 간 같은 숫자는 같아야 한다: 파이프라인 합계, 자금 소요 = 조달, 인원 = 인건비, 매출 = 물량 × 단가, 비율 합 100%. 계산은 직접 다시 돌려 확인한다.
- 모르는 숫자는 만들지 않는다. 빨간 `[ ]`로 비워 대표가 채우게 한다.

## 2-4. 근거·출처

- 표·그래프·사진마다 아래에 작은 글씨 출처(매체·날짜·기사 제목 또는 기관·성적서 번호).
- 뉴스는 표로 정리: 날짜 · 매체 · 핵심 수치/인용. 대표나 멘토가 준 기사·인포그래픽은 출처를 달아 그대로 써도 된다.
- 접근이 막힌 기사는 우회하지 않고 원문 텍스트를 받아 쓴다.
- 대표만 가진 가장 강한 근거(예: 실제 견적·발주 이력)는 상담 때 질문해서 받아 넣는다.

## 2-5. 쓰지 않는 표현

- 자금 구어 표현: "갚지 않는 돈 → 갚는 돈", "돌아오는 돈" → "정부지원금 / 정책자금·보증 / 자기자금·매출"
- 이전 탈락·지적 사항 반영 서술
- 과장 형용사·부사(혁신적인, 획기적인, 차세대, 압도적인)와 보고서체 수식
- 노출된 마크다운 기호(`**`, `#`), 이모지
- 포지셔닝과 맞지 않는 "플랫폼" 표현 — 사업 정체성에 맞는 말로
- 경쟁사 비하. 비교는 사실(형태·단계·수치)로만

## 2-6. 시각화 — 표만 이어지지 않게

| 하고 싶은 말 | 도식 |
|---|---|
| 값이 오르고 있다 | 우상향 선그래프(주석으로 시작·끝·배수) |
| 시장 크기 | 퍼널 |
| 돈과 물건이 어떻게 흐르나 | 흐름도 + 돈 흐름 화살표 |
| 고객이 어디까지 왔나 | 파이프라인 단계 도식 |
| 언제 무엇을 | 간트(단계 음영 + ◆) |
| 돈이 어디서 오나 | 단계별 조달 블록 + 합계 막대 |
| 어디까지 크나 | 계단 도식 |
| 무엇으로 넓히나 | 2×2 매트릭스 |
| 기술·인증 순서 | 연도 × 두 줄 로드맵 |
| 누가 하나 | 조직도(내부/외부) |
| 왜 이 대표인가 | 경력 타임라인 |

- 도식 안 글자는 인쇄 크기 7pt 이상이 되게 그린다(문서 폭에 줄였을 때 기준).
- 그림 번호 `[그림 N]`은 문서 순서대로 다시 매기고, 캡션은 무엇을 보여 주는지 결론형으로.
- 색: 네이비/블루 기본, 앰버 포인트, 빨강은 강조·확인 필요에만.

## 2-7. 사진·증빙 — 붙임이 아니라 본문 근거 옆에

- 대표가 초안에 넣은 사진은 그대로 살려 해당 근거 옆에 둔다.
- 없는 증빙은 점선 `[증빙 삽입]` 칸 + 무엇을 넣을지 한 줄(시험성적서 요약면, 특허 접수증, NDA 서명면, 협약서, 메일 캡처 등).
- 상대 회사명·서명·개인정보는 가린다.

## 2-8. 서식 기본값

- 양식 규정이 최우선(쪽수 한도, 글꼴 크기, 줄간격, 문항별 글자 수, 파일명 "성명_1R 사업계획서", 붙임 한도).
- 맑은 고딕, 문항 머리 남색 띠, ■ 소제목, ▪ 글머리, 표 머리 연한 남색.
- 빨간 `[ ]` = 대표 확인·입력 필요. 수정안 1쪽 멘토 메모에 목록으로 다시 적는다.
- 빈 쪽이 생기지 않게 쪽 나눔은 다음 문단의 '앞에서 쪽 나눔'으로 건다.
