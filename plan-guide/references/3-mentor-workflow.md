# 3. 멘토링 진행과 산출물

## 회차 흐름

| 단계 | 할 일 | 산출물 |
|---|---|---|
| 사전 진단 | 양식·대표 초안·프로필·이전 피드백을 받아 빠진 칸·숫자 불일치·결론 없는 소제목을 찾음 | 진단 메모 |
| 상담 준비 | 진단을 프레젠테이션 PDF로 | 상담자료 PDF |
| 상담 | 대표가 직접 정해야 할 것은 빈칸 워크시트로 현장에서 함께 정함 | 상담 기록 |
| 수정안 | 양식 문항 그대로 다시 씀 | 수정안 docx + 미리보기 PDF |
| 반영 | 대표·멘토 피드백을 같은 패턴 전체에 적용 | 수정안 갱신 |
| 전달 | 번호 붙인 파일 묶음 | zip |

## 상담자료 PDF 구성 (예시 순서)

1. 결론 한 장 — 지금 계획서가 지침대로 됐는지, 가장 큰 보완 3가지
2. 숫자 불일치 표 — 어디와 어디가 다른지
3. 소제목 진단 — 현재 소제목 vs 결론형 제안
4. 보완할 근거 — 그래프·기사·비교표 시안
5. 대표에게 물을 질문 — 가장 강한 근거(실제 견적·발주 이력 등)를 받아 내는 질문 + 빈칸 워크시트
6. 일정 — 수정안·제출 마감

## 수정안 문서

- 1쪽: **멘토 메모(제출 시 삭제)** — 바꾼 점 목록, 대표가 채울 `[ ]` 목록, 양식 규정 확인 사항
- 표지 → Q1 → Q2 → Q3 → Q4 (양식 문항명·안내문 그대로)
- 대표 원고에서 살릴 문장·사진은 살리고, 바꾼 이유는 메모에 한 줄씩

## 참고 사례 자료

- 다른 기수 완성본을 보여 줄 때는 핵심 내용을 블러 처리해 "이 정도로 표·그래프가 들어가야 한다"는 시각화 수준만 전달한다.

## 브랜딩·윤리

- 모든 멘토링 산출물 표기: **"모두의창업 N기 책임멘토 김윤경"** (파키라랩 로고·직함보다 우선).
- 멘토가 같은 팀을 평가한 이력이 있어도 심사 내용·점수는 멘티 자료에 넣지 않는다. 근거는 공고에 공개된 평가 기준만.
- 멘토 본인 사업장을 테스트베드로 쓰면 구매가 아닌 무상 실사용 테스트로 한정한다.
