# 4. 제출 전 점검표

## 구조
- [ ] 각 문항의 ■ 소제목만 이어 읽어도 이야기가 된다
- [ ] 소제목이 모두 `키워드 — 결론` 형식이고 핵심 숫자가 들어 있다
- [ ] Q1: 동기 → 목적 → 왜 지금 → 목표 시장 → 매출 목표 → 마무리 한 줄
- [ ] Q2: 개발 방안 → 준비 정도 → 차별화 방안 → 대표 역량 → 팀 구성
- [ ] Q3: 사업화 계획 → 추진일정 → 자금 소요 → 자금 조달(정부지원사업 일정표 기준)
- [ ] Q4: 목표 → 아이템 고도화 → 기술·인증 → 조직 확장 → 마무리
- [ ] 요약 상자는 문항 끝에만 있다

## 문장
- [ ] 목표·계획은 의지형 어미, 이미 한 일은 사실형
- [ ] "잡았음 / ~하겠음 / 갚지 않는 돈" 같은 표현이 없다
- [ ] 이전 탈락·지적 사항 반영 서술이 없다
- [ ] 과장 형용사·마크다운 기호·이모지가 없다

## 숫자
- [ ] 파이프라인 합계, 자금 소요 = 조달, 단계별 합, 비율 합 100%
- [ ] Q1 목표 시장·Q1 매출 목표·Q4 목표가 서로 이어진다
- [ ] 팀 인원 = Q3 인건비
- [ ] 큰 숫자는 하나로 표기, 출처는 아래 작은 글씨

## 시각화·증빙
- [ ] 문항마다 도식이 있고, 표가 연속 3개 이상 이어지지 않는다
- [ ] 그림 번호가 순서대로다
- [ ] 사진·증빙은 붙임이 아니라 본문 근거 옆에 있다
- [ ] 회사명·서명·개인정보는 가렸다

## 양식
- [ ] 쪽수 한도·글꼴 크기·줄간격·문항별 글자 수를 공고 원본으로 확인했다
- [ ] 파일명 "성명_1R 사업계획서"
- [ ] 멘토 메모 페이지는 제출 전 삭제하도록 안내했다
- [ ] 빨간 `[ ]`가 모두 채워졌는지 대표와 확인했다
