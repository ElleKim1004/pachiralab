# 1. 작성 의도별 작성법과 개요

모두의창업 1R 사업계획서는 4문항(P-S-S-D)이다. 마지막 D는 팀이 아니라 **Develop(향후 발전방안)**이다.

| 문항 | 심사위원에게 증명할 것 | 한 줄 의도 |
|---|---|---|
| Q1 문제 인식 | 왜 이 문제를, 왜 지금, 얼마나 큰 시장에서 | 동기 → 목적 → 시장 → 목표 매출 |
| Q2 실현 가능성 | 정말 만들 수 있고, 이미 준비됐고, 남과 다르며, 이 대표가 해낼 사람인가 | 개발 방안 → 준비 정도 → 차별화 → 대표 역량·팀 |
| Q3 성장전략 | 누구에게 어떻게 팔고, 언제 무엇을 하며, 돈은 얼마가 어디서 오나 | 사업화 계획 → 추진일정 → 자금 소요·조달 |
| Q4 향후 발전방안 | 3~5년 뒤 어디까지 가나 | 목표 → 아이템 고도화 → 기술·인증 → 조직 확장 |

## 공통 설계

- **■ 소제목 = 결론 완결 문장.** `■ N. 키워드 — 결론`. 예고형("~에 대하여", "~현황") 금지.
- **소제목 사슬.** 한 문항의 ■만 이어 읽어도 이야기가 된다. 다 쓴 뒤 ■만 뽑아 읽어 보고, 앞뒤가 끊기면 순서나 문장을 고친다.
- **묶음 라벨.** 문항 안에 성격이 다른 덩어리가 있으면 굵은 라벨로 묶는다. 예: `[개발 방안]` `[준비 정도]` `[차별화 방안]` `[대표 역량 · 팀 구성]`.
- **요약은 맨 끝.** 문항 요약 상자·숫자 카드는 그 문항 마지막에 둔다. 맨 앞에 두지 않는다.
- **문항당 도식 1~2개 이상.** 어떤 도식을 넣을지는 아래 문항별로 정해 두었다.

## Q1. 문제 인식 — 동기 → 목적 → 왜 지금 → 목표 시장 → 매출 목표

멘토 지침: "아이디어의 개발 동기, 그 목적, 목표 시장을 확인한 결과 이 정도 시장이 있음을 확인했고, 그중 SOM의 1%를 타깃으로 잡아 몇 년 뒤 이 매출을 달성할 목표로 사업을 시작했다."

| ■ | 쓰는 법 | 도식·표 |
|---|---|---|
| 1. 개발 동기 | 대표가 현장에서 **반복해서 겪은 문제**를 이해관계자 차원으로 나눠 소제목에 넣는다. 예: "N년 현장에서 생산자·소비자·환경 세 차원의 문제를 겪었음" | 차원별 글머리 |
| 2. 개발 목적 | 차원별 문제를 무엇으로 없애려는지 | 표: 차원 · 문제 · 근거 · 우리가 바꾸는 것 |
| 3. 왜 지금 | 가격·규제·소비 변화가 **지금** 일어나고 있다는 증거. 업계의 대응(예: 고가 라인과 대체재 라인으로 이원화)까지 | **우상향 선그래프**(막대보다 선) + 뉴스 표(날짜·매체·핵심 수치) + 기사 인포그래픽(출처 표기) |
| 4. 목표 시장 | 큰 시장은 숫자 하나로("470조 원"). SAM은 **우리 제품이 실제로 대체하는 시장**, SOM은 그중 목표 점유율 → "1%인 ○억 원을 목표로 도전하고자 함" | 퍼널(TAM→SAM→SOM) |
| 5. 매출 목표 | 연도별 물량·매출·SOM 대비 비율, SOM 달성 연도 | 표 |
| 마무리 | 제품 단가 설명이 아니라 **"이 시장에서, 이 타이밍에, 내가 얼마나 잘할 수 있는지"** 한 줄 | 결론 상자 + 카드 4개(왜 지금 · 왜 나 · 증명 · 목표) |

- 시세 근거가 연속으로 없으면 같은 기준(같은 등급·같은 매체 인용)의 시세를 모아 하나의 계열로 만든다. 검증되지 않은 수치("그때도 2배 올랐다")는 그래프에 넣지 않는다.
- 업종에 따라 TAM/SAM/SOM이 맞지 않으면(로컬·생활 서비스) 타깃 수 × 단가 같은 맞는 수요 추정을 쓴다.
- **넣지 않는 것:** 이전 라운드 탈락·지적 사항을 반영했다는 서술("1차 탈락 후 재설계" 등). 개선은 내용으로 보여 준다.

## Q2. 실현 가능성 — 개발 방안 → 준비 정도 → 차별화 방안 → 대표 역량 · 팀

멘토 지침: "실현가능성은 아이디어의 개발방안, 준비정도, 차별화 방안이다. ■는 차례대로 논리가 이어지고, 심사위원이 핵심만 봐도 이해되게."

| 라벨 | ■ (예시 사슬) | 쓰는 법 | 도식·표·증빙 |
|---|---|---|---|
| 개발 방안 | 1. 원리 | 무엇을 어떤 원리로 만드는가 | 공정 단계표 + 대표 사진(원료·시제품·구조) |
| | 2. 생산 | 어디서, 언제, 얼마나 | 단계별 생산처·물량·시기 표 |
| 준비 정도 | 3. 성능 | 공인 수치와 호환성 | 숫자 카드 + [증빙] 시험성적서·현장 사진 |
| | 4. 사업화 | 이미 끝낸 것과 진행 중인 것 | 완료/추진 표 + [증빙] 특허 접수증·NDA·협약 |
| 차별화 방안 | 5. 차별점 | 비교 대상 중 우리만 가진 조합 | 경쟁 비교표(형태·단계 행 포함) + 가격 그래프 |
| | 6. 진입장벽 | 따라오기 어려운 이유 | 표: 장벽 · 내용 · 경쟁사가 아직 못 한 이유 |
| | 7. 남은 과제 | 숨기지 않고, 언제 무엇으로 근거를 닫을지 | 표: 남은 과제 · 대응(시험·일정) |
| 대표 역량 · 팀 | 8. 대표 역량 | **이 실현 방안을 해낼 적임자**임을 증명 | 숫자 카드 + 경력 타임라인 도식 + **매핑 표**(실현 방안에서 해야 할 일 ↔ 대표가 이미 해 온 일) + 한 줄 |
| | 9. 팀 구성 | 1인이어도 팀은 필수. 영입 중인 팀원, 채용 예정, 외부 협력 | 조직도 도식(내부/외부) + 표: 구분 · 담당 · 필요 역량 · 충원 계획 |

- 대표 역량은 경력 나열이 아니다. Q2·Q3에서 해야 할 일 하나하나에 "이미 해 본 일"을 짝지어 보여 준다.
- 팀원은 역할·필요 역량·합류 시기·보상 방식(지분, 법인 설립 후 급여 등)까지 쓴다. 인원·인건비는 Q3 자금 소요와 맞춘다.

## Q3. 성장전략 — 사업화 계획 → 추진일정 → 자금 소요 및 조달

| 라벨 | ■ | 쓰는 법 | 도식·표 |
|---|---|---|---|
| 사업화 계획 | 1. 사업 구조 | 무엇을 누구에게 어떤 단위로 팔고, 첫 고객 1건이 얼마인가. 고객이 바라는 공급 조건(기사 근거) | 흐름도: 원료 → 우리 → 고객 → 최종 소비자 + 돈의 흐름 |
| | 2. 판로 | 고객 후보·단계·물량·확률, 이번 라운드 안에 만들 첫 결과(북극성 지표) | 파이프라인 단계 도식 + 합계·가중 금액 + [증빙] 메일·연결 캡처 |
| 추진일정 | 3. 추진일정 | 등록·첫 납품·생산 가동 시점 | 간트(단계 음영 + ◆ 확인 시점) + 연도별 물량·매출 카드 |
| 자금 소요 및 조달 | 4. 자금 소요 | 단계별 금액과 산출 근거(단가 × 수량) | 표: 단계 · 금액 · 산출 근거 |
| | 5. 자금 조달 | **사업자등록 시점 이후 정부지원사업 공고 일정표대로** 구조화 | 단계별 조달 도식(지원금 / 보증·정책자금 / 자기자금·매출) + 표: 조달처 · 접수 시기 · 지원 규모 · 쓰는 곳 · 반영액 |

- 조달 합계 = 소요 합계. 단계별 합도 맞춘다. 비율은 반올림 후 합 100%.
- 지원 규모(상한액)와 계획 반영액을 구분한다. 자부담 비율·같은 해 중복 수혜는 공고로 [확인].
- 선정이 불확실한 사업은 합계에서 빼고 "선정 시 추가 여력"으로 적는다. 지분 투자는 실적이 쌓인 뒤 시점으로.

## Q4. 향후 발전방안 — 목표 → 아이템 고도화 → 기술·인증 → 조직 확장

| ■ | 쓰는 법 | 도식·표 |
|---|---|---|
| 1. 목표 | 3~5년 뒤 물량·매출, Q1의 목표 시장(SOM)으로 이어짐 | 계단 도식(연도별 단계) + SOM 목표 칸 |
| 2. 아이템 고도화 | 지금 기술로 기존 시장 → 새 시장 → 새 기술 → 새 기술 × 새 시장 순서 | 2×2(기술 × 시장)에 ①②③④ 순서·연도 |
| 3. 기술·인증 | R&D 지원사업과 연결한 기술 과제, 고객이 요구하는 인증·ESG를 쌓아 갈 순서 | 연도 × 두 줄(기술 / 인증) 로드맵 → 도달점 |
| 4. 조직 확장 | 연도별 인원·늘리는 역할·연결되는 계획 | 표 + 협력·원료 확대 글머리 |
| 마무리 | 의지 문장 두 줄 | 결론 상자 |
