# moduchang-2nd-round-evaluator

모두의창업 프로젝트 **2차 라운드** 평가위원용 채점·평가의견 초안 작성 스킬입니다.

## 무엇을 하는 스킬인가

- 지원서를 4개 지표(각 25점, 총 100점)로 채점
- 200자 이상 평가의견 초안 작성 (사용자가 최종 제출 전 반드시 재작성)
- 재도전자 Q8 개선도 가점(최대 3점) 판단
- 60건 이상 대량 평가 시 톤·기준 일관성 유지

## 언제 트리거되나

- "2차 평가해줘", "2라운드 평가", "모두의창업 점수 매겨줘"
- 지원서에 **Q8("2차 지원서에는 1차 지원서보다 어떤 점이 더 개선되었나요?")** 항목이 있을 때
- 평가 기간: 2026.09.23 ~ 09.29

## 핵심 원칙

1. **Claude는 초안까지**. 최종 제출은 사용자가 자신의 언어로 재작성 (2차 가이드에 AI 원문 붙여넣기 금지 명시)
2. **점수 감각 상향**. 진출 80점 이상, 예비 70~79점, 탈락 60~69점. 1차 대비 전반적으로 후한 채점
3. **PoC와 팀 구성 중시**. 2차에서 새로 추가된 평가 요소
4. **도전자가 볼 수 있는 글**임을 기억. 존중형 어조 유지

## 사용법

Claude 계열 LLM 환경에서 이 폴더의 `SKILL.md`가 로드되면, 위 트리거 발화가 감지될 때 스킬이 활성화됩니다.
