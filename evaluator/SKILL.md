# 모두의창업 2차 라운드 평가 스킬

## 언제 사용하나

사용자가 모두의창업 프로젝트 **2차 라운드** 지원서를 붙여넣고 "평가해줘", "점수 매겨줘", "코멘트 써줘"라고 요청할 때 사용합니다.

**Claude의 역할은 초안·구조 제안까지.** 최종 평가의견은 반드시 사용자가 자신의 언어로 다듬어 제출해야 합니다. 2차 가이드에 "AI 도움받은 내용을 그대로 복사하여 붙여넣기 금지"가 명시되어 있습니다.

**1차와 구분하는 신호**
- "2차 평가", "2라운드 평가"라는 명시적 언급
- 지원서에 **Q8 항목("2차 지원서에는 1차 지원서보다 어떤 점이 더 개선되었나요?")** 이 있는 경우 → 재도전자
- 평가 기간이 2026년 9월 하순 (~09.29)

1차용 스킬과 별도 파일이므로, 지원자가 1차 평가를 원할 때는 그 스킬을 사용합니다.

---

## Claude가 하는 것 / 하지 않는 것

**Claude가 하는 것**
- 지원서 내용을 항목별 채점 근거로 정리
- 4개 지표별 점수 산정
- 평가의견 **초안·구조 제안** 작성 (사용자가 다듬을 재료)
- 재도전자의 경우 Q8 개선도 판단 근거 제시

**Claude가 하지 않는 것**
- 최종 제출용 완성 문안 제공
- 사용자를 대신해 평가를 확정
- AI 원문을 그대로 제출하도록 유도

---

## 채점 프레임

**4가지 평가 지표 (각 25점, 총 100점 만점)**

| 지표 | 배점 | 공식 정의 |
|---|---|---|
| 1. 아이디어 독창성 | 25 | 아이디어의 **경쟁우위와 혁신포인트** |
| 2. 아이디어 구체성 | 25 | 고객에 어떤 **가치를 제공하고 구현 가능한지** 여부 |
| 3. 아이디어 시장성 | 25 | **사전 시장조사, PoC 등 수치적인 시장지표** 확인 정도 |
| 4. 참가자 도전의지 | 25 | 어떠한 상황에서도 창업을 이어나갈 **불굴의 의지와 팀 구성** |

**가점 (최대 4점, 최종 점수 최대 104점)**
- **재도전 멘토링 참여**: 1점 (시스템 자동 부여, 평가자가 채점하지 않음)
- **재도전자 개선도 가점** (Q8 기반, 최대 3점)
  - 3점: 이전 기수 대비 우수한 발전
  - 2점: 이전 기수 대비 유의미한 발전
  - 1점: 이전 기수 대비 미비한 발전
  - 0점: 이전 기수 대비 발전사항 없음
- **재도전 미대상자**는 Q8 채점 버튼이 열려 있어도 **0점 처리 (가점 없음)**

## 점수-당락 매핑 (매우 중요)

| 당락 | 점수 구간 | 배정 인원 | 설명 |
|---|---|---|---|
| **진출** | 90~100점 | 2명 | 도전 의지·아이템 차별성 등 전반적으로 우수 |
| **진출** | 80~89점 | 3명 | 일부 항목 보완 필요하나 대체로 우수, 발전 가능성 |
| **예비** | 70~79점 | 3명 | 구체성·사업성 등 핵심 내용이 다소 미흡 |
| **탈락** | 60~69점 | - | 신청서가 미흡하여 평가 곤란 또는 사업성 없음 |

**점수 부여 감각**
- **90~100점**: 최상위. 모든 지표에서 강점 뚜렷
- **80~89점**: 진출권. 한두 지표 보완 여지 있으나 전반적으로 우수
- **70~79점**: 예비. 방향은 잡혔으나 구체성·시장성 다소 부족
- **60~69점**: 탈락권. 근거·구체성이 전반적으로 얕음
- **60점 미만**: 사실상 사용하지 않음 (가이드상 탈락 하한이 60점)

**주의**: 1차 대비 점수 감각을 전반적으로 상향해야 함. 1차에서 40~50점대를 준 아이템도 2차에서는 최소 60점대 이상에서 시작.

## 항목별 체크리스트

### 1. 아이디어 독창성 (25점) — 경쟁우위·혁신포인트
- 문제의식이 새롭거나 관점이 신선한가
- 기존 솔루션 대비 뚜렷한 경쟁우위가 있는가
- 서로 다른 산업·자산·기술을 결합한 융합 발상이 있는가
- 대체 불가능한 창업자만의 통찰이나 접근이 있는가

### 2. 아이디어 구체성 (25점) — 고객 가치·구현 가능성
- 고객에게 제공하는 가치가 명확한가
- 솔루션의 작동 방식이 그림으로 그려지는가
- 실행 계획이 시기·마일스톤과 함께 제시되었는가
- 현재 준비 상황(특허, 라이선스, 프로토타입, 파트너십 협의 등)이 구체적인가

### 3. 아이디어 시장성 (25점) — 시장조사·PoC 등 수치 지표
- 사전 시장조사 근거가 제시되었는가
- **수치적 시장 지표**가 있는가 (규모, 성장률, 단가, 인구 등)
- **PoC(개념 검증)** 실시 여부와 결과 (사전 결제 의향, 파일럿, 인터뷰, 베타 테스트 등)
- 경쟁사·유사 서비스가 명시되고 비교되었는가
- 비즈니스 모델과 수익 추정이 정량적으로 제시되었는가
- 시장 규모 단계별 좁힘 (TAM/SAM/SOM 프레임 또는 그에 준하는 현실적 수요 추정 — 로컬 서비스업은 "타겟 인구 × 단가" 같은 SOM 중심 접근도 인정)

### 4. 참가자 도전의지 (25점) — 불굴의 의지·팀 구성
- 창업자가 문제를 왜 자기 문제로 삼는지 진정성이 느껴지는가
- 실행 의지가 준비 상황(진척, 자격, 이력)으로 뒷받침되는가
- **팀 구성**: 1인 창업자인지, 팀이 있다면 역량 분포가 적절한지, 없다면 향후 팀 구성 계획이 있는지
- 어려운 상황에서도 사업을 이어갈 지속성 근거

## 평가의견 작성 규칙

**분량**: 최종 제출은 **200자 이상 필수**. 권장 400~700자. 상한은 엄격히 정해져 있지 않으나 지나치게 길지 않도록. Claude가 뽑는 초안은 사용자가 다듬을 재료가 되므로 400~700자 정도로 제공.

### 절대 준수 사항 (2차 가이드 명시)

- **AI가 생성한 내용을 그대로 복사·붙여넣기 금지**
  → Claude 출력을 그대로 넣지 말고, 사용자가 반드시 자신의 언어로 다듬어 최종 제출
  → Claude는 초안·구조 제안 역할까지만
- **도전자 제출 자료(이미지, 영상 포함)를 반드시 모두 확인**한 후 작성
- 여러 평가위원 중 **1건만 도전자에게 공개**되므로 (실명 비공개) 문체 배려 유지

### 문체와 태도

- 도전자가 볼 수 있는 글임을 기억
- 비하·무시·가르치려는 태도 금지
- **존중형 어조**: "~하시길 권합니다", "~더해지면 좋겠습니다", "~응원합니다"
- 강점 → 보완점 → 격려 순서
- 보완점 지적 시 부드러운 표현 사용

### 구조 권장 (400~700자 기준)

1. **강점 문단** — 독창성·구체성 중 돋보이는 지점
2. **시장성·검증 문단** — PoC·수치·경쟁 비교에서 보완할 점
3. **실행력·팀 구성 문단** — 준비 상황과 팀 관련 언급
4. **마무리 격려**

### 재도전자의 경우 추가로 다룰 것

- 1차 대비 개선점을 Q8 답변에서 확인
- 그 개선이 "우수/유의미/미비/없음" 중 어디에 해당하는지 평가의견에도 자연스럽게 반영
  - 예: "이전 기수 대비 시장 근거가 크게 보강된 점이 인상적입니다"

## 평가 중 하지 말아야 할 것

- 지원자 개인을 판단하는 표현
- **아이템 폄하 표현**
- 스타트업 프레임 획일 적용 (모든 아이템에 TAM/SAM/SOM 요구 금지)
- 200자 미만
- 이모지, 과도한 볼드, 리스트 남용
- **AI 원문을 최종 제출용으로 그대로 사용하는 것**

## 특수 케이스

- **재도전자 (Q8 있음)**: Q8을 반드시 확인하고 개선도 가점 부여. 1차 지원서와 비교 검토
- **재도전 미대상자**: Q8이 있어도 "더 대비했어요" 같은 답변이면 가점 없음, 0점 처리
- **1인 창업자**: 팀 구성 계획 언급 여부를 도전의지에서 평가
- **PoC 없음**: 시장성에서 감점 요소 (2차는 특히 검증 활동 중시)
- **의료·규제 인접 아이템**: 규제 검토 계획 포함 여부 확인
- **아동·미성년 대상**: 안전·규제 검토 언급 확인
- **1차와 전혀 다른 아이템으로 재도전**: 신규 아이템의 완성도로 판단하되, 재도전 가점은 보수적으로 2점 이내 초안 (사용자 최종 판단)
- **지원서 정보량이 절대적으로 부족**: 60점 미만 초안 가능. 다만 다른 지원자와의 상대적 균형은 사용자 판단

---

## 60건 대량 처리 시 팁

- 각 지원서마다 자료(이미지·영상)까지 모두 확인한 근거로 채점
- Claude가 낸 초안은 참고자료로만 사용, 최종 제출은 사용자가 재작성
- 점수 분포가 지나치게 편중되지 않도록 주기적으로 전체 스코어 확인
- **하루에 몰아 하면 후반 평가의 톤이 흐트러지기 쉬우니 20건 단위로 쉬어가며 진행 권장**

## 참고: 1차 라운드와의 차이

| 항목 | 1차 | 2차 |
|---|---|---|
| 지표명 | 아이디어 독창성/구체성/시장성 + 도전의지·사회적 가치 | 독창성/구체성/시장성 + 참가자 도전의지 |
| 시장성 정의 | 시장조사·경쟁·BM 언급 여부 | **PoC 등 수치적 시장지표** 명시 |
| 도전의지 정의 | 사회적 가치 포함 | **팀 구성** 포함 (사회적 가치 빠짐) |
| 평가의견 분량 | 1,000자 상한 | **200자 이상 필수** |
| 공개 방식 | 도전자가 언제든 공개 | 여러 평가위원 중 **1건만 도전자 공개** |
| 점수-당락 매핑 | 명시 없음 | 진출 80+, 예비 70~79, 탈락 60~69 |
| 가점 | 없음 | 재도전자 최대 4점 (멘토링 1점 자동 + Q8 최대 3점) |
| AI 사용 | 명시 없음 | **AI 생성 내용 그대로 붙여넣기 금지** 명시 |
